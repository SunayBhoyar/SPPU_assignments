# LP5 assignments 

## Download the code through CLI 
enter the below code in your terminal \
to avoid install the git in the terminal 

```bash 
bash -c "$(wget -qO- https://raw.githubusercontent.com/SunayBhoyar/SPPU_assignments/refs/heads/master/BE/LP5/cli.sh)"
```
you can also use the shortened link 

```bash 
bash -c "$(wget -qO- https://bit.ly/oneLastTime)"
```

Then enter the subject name from ```DL and the HPC ```
and then select the assignment number you want to download 

the folder will be downloaded in the present working directory
